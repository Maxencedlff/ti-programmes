# Programmes pour TI-83 Premium CE Édition Python

## BINAIRE.py
Conversion décimal ⇄ binaire, nombres négatifs et à virgule compris (5,75 ⇄ 101.11, calcul exact sans arrondi), et complément à 2 sur 8, 16, 32 ou 64 bits (ou automatique), affiché par groupes de 4 bits.

Télécharger la dernière version : https://github.com/Maxencedlff/ti-programmes/releases/latest/download/BINAIRE.py

Installation : TI Connect CE (gratuit, education.ti.com), calculatrice branchée en USB, glisser le fichier dans la fenêtre. Sur la calculatrice : `prgm` → Python → BINAIRE.
